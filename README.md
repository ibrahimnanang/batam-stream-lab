# Batam Stream Lab — company website

Independent marketing site for **Batam Stream Lab** (streaming, hybrid events, LED/visual production).

This project is separate from older **Lumen LED / solar** company-profile repos: different brand, codebase, routes, content, and `package.json` name (`batam-stream-lab-web`).

## Stack

Next.js App Router · TypeScript · Tailwind · Framer Motion · next-themes · bilingual JSON (`messages/`)

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Deploy notes

Configurable for Railway/Vercel; start command builds with `npm run build` then `npm run start`.
